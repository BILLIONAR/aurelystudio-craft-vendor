# AurelyStudio Craft Fair Planner

The existing full product is upgraded to v3.0.0. Inventory now supports custom categories, subcategories and item types; multi-item orders include dates, notes, sources, deposits and balances. Device Sync lets each business create its own private workspace and connect its iPhone and iPad. Original craft fair, stock history, return, analytics, printing and Theme Studio tools remain.

The full build keeps the original aurely-vendor-os-v1 storage key, migrates v1/v2 records and saves the original pre-upgrade JSON locally before a schema upgrade. It includes no demo restrictions. The Cloudflare demo is built separately with runtime.js publicDemo=true.

Full app: https://billionar.github.io/aurelystudio-craft-vendor/

Public demo: https://aurelystudio-vendor-demo.pages.dev/

See START-HERE.txt for customer setup, sync-backend/ for the owner-controlled encrypted sync service, and fonts/ and vendor/ for third-party licenses. No private workspace credentials are published.
